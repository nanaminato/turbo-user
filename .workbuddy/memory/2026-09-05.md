# 2026-09-05

## Settings 页面升级 — 对齐后端新版 OpenAI API / 多供应商

后端 `Turbo.Auth` 已经把 `NoModelChatBody` 扩展出 `reasoning_effort` / `verbosity` / `thinking_budget`，并由 `OpenAiChatHandler`（o 系列、gpt-5 系列）和 `GoogleChatHandler`（Gemini 2.5）按模型兼容性过滤。`ProviderCatalog` 把 OpenAI / Google / Anthropic / Alibaba / Novita / Twitter / ApiMart 都登记好了。Settings 页面之前只透传老 OpenAI 套词，这次把前端也对齐。

### 改动文件

- `src/models/enumerates/enum.type.ts` — 新增 `HandlerType` enum、`ProviderDefinition` 接口、`providerCatalog` 常量、`reasoningEfforts` / `verbosityLevels` / `thinkingBudgetPresets` 列表，严格对齐后端 `ProviderCatalog`。
- `src/models/enumerates/index.ts` — `export type {ProviderDefinition}`（因为 tsconfig 启用了 `isolatedModules`，类型再导出必须用 `export type`）。
- `src/models/chat-stores/configuration.interface.ts` — `ChatStreamConfiguration` 新增 `reasoning_effort`、`verbosity`、`thinking_budget` 三个可选字段。
- `src/services/db-services/configuration.service.ts` — `default_configuration()` 给三个新字段 `undefined` 默认值，避免污染本地数据库。
- `src/services/fetch_services/turbo.service.ts` — `fetchChat` 通过 `appendIfPresent` / `appendIfNumber` 仅在用户显式配置时把字段加进请求体；缺失时不发送，与旧版本行为完全兼容。
- `src/pages/settings/settings.html` — 在「对话默认属性」card 之后新增「扩展对话参数」card（reasoning_effort / verbosity / thinking_budget 三栏下拉），以及「支持的服务商」展示卡（只读）。
- `src/pages/settings/settings.ts` — 引入新的枚举常量，新增 `updateReasoningEffort / updateVerbosity / updateThinkingBudget / thinkingBudgetModel / thinkingBudgetLabel` 辅助方法。用 `[ngModel] + (ngModelChange)` 而不是 `[(ngModel)]`，方便把 null 翻译回 undefined。
- `src/assets/i18n/{zh,en,jp}.json` — 新增 14 个 i18n key（`advancedChatParameters*`、`reasoningEffort*`、`verbosity*`、`thinkingBudget*`、`providerCatalog*`、`optionNotSet` 等）。

### 验证

`ng build --configuration development` 通过（4.1s）；`tsc -p tsconfig.app.json --noEmit` 零错误。

### 注意点

- `ChatStreamConfiguration` 新字段都是 optional，旧版本地数据库里的配置对象不需要迁移即可工作。
- `thinkingBudget` 用 `null` 表示「不发送」（与 `undefined` 等价），整数 `-1` = 动态思考，`0` = 不思考。
- 后端 `OpenAiChatHandler` 内部对 reasoning 模型会忽略 `temperature / top_p / penalties`，SDK 不支持时会走原生 HTTP 通道。前端不需要做特殊判断。
- 服务商目录是只读参考，密钥维护仍走 admin 控制台的 secrets 模块。
