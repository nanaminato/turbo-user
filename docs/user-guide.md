# 用户指南

## 开始使用

1. 打开管理员提供的 Turbo AI 地址，注册账户或登录已有账户。
2. 在聊天页顶部选择模型；模型列表由管理员配置。没有可选模型时，请联系管理员。
3. 输入问题并发送。回复会持续显示；再次点击发送按钮可停止当前生成。
4. 在左侧边栏新建、切换或删除本地会话。移动设备可用页面顶部按钮展开导航。

## 聊天与文件

聊天支持 Markdown、代码块和系统提示词。使用输入框上方的“选择文件”可将文件内容作为上下文提交；服务端决定可接受的文件类型和大小，常见的 TXT、DOCX 与 PDF 需要由服务端启用文本提取功能。

长文件和超长对话会增加模型调用成本与等待时间。提交前请只保留与问题相关的内容，并避免把密码、访问令牌、私人密钥或其他敏感信息发送给模型。

## 图像与多媒体

- 图像工作室：选择管理员启用的图像模型，填写描述后生成。部分供应商返回的是有期限的图片链接；满意的结果请及时下载。
- 文本转语音：输入文字或先提取文档文本，再选择可用语音模型生成音频。
- 语音转文字 / 翻译：上传音频后选择转写或翻译。处理时长取决于文件大小和后端模型。

如果某项能力不可用，通常表示账户角色不足、模型未启用，或服务端尚未配置相应供应商。

## 个人设置与数据

“设置”中可以修改主题、语言、字号、默认模型参数，以及导入或导出本机设置。设置和本地会话保存在当前浏览器的本地存储中；更换浏览器、清理站点数据或使用“重置本地数据”都会清除这些本地内容。导出设置可用于迁移个人偏好，但不应包含或分享任何敏感内容。

## 常见问题

| 现象 | 建议 |
| --- | --- |
| 登录后没有模型 | 请管理员为账户分配相应角色，并启用至少一个模型路由。 |
| 回复失败或中断 | 确认网络连接后重试；持续失败时请提供时间、所选模型和错误提示给管理员。 |
| 页面无法连接后端 | 部署者应检查前端地址、后端服务状态和 CORS 配置。 |
| 生成图片或音频失败 | 确认账户有权限，且所选模型及其供应商密钥仍处于启用状态。 |
